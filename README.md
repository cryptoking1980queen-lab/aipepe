## 📤 GitHub Deployment

### Repository Setup
```bash

git clone https://github.com/cryptoking1980queen-lab/aipepe.git
cd aipepe

# Copy files from sahara folder
cp -r /Users/sandhya/CascadeProjects/sahara/* .

# Add and commit changes
git add .
git commit -m "Add Neural Pepe professional website"

# Push to GitHub
git push origin main
```

### GitHub Pages Setup
1. Go to repository settings
2. Enable GitHub Pages
3. Select source: "Deploy from a branch"
4. Choose branch: "main"
5. Select folder: "/ (root)"
6. Save and wait for deployment
