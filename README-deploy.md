## ⚡ Quick Deployment

### 1. Clone Repository
```bash
git clone https://github.com/cryptoking1980queen-lab/aipepe.git
cd aipepe
```

### 2. Copy Files
```bash
# Copy all files from github-deploy folder
cp -r /Users/sandhya/CascadeProjects/sahara/github-deploy/* .
```

### 3. Deploy
```bash
git add .
git commit -m "Deploy Neural Pepe website with banner"
git push origin main
```

### 4. Enable GitHub Pages
1. Go to repository settings
2. Enable GitHub Pages
3. Select source: "Deploy from a branch"
4. Choose branch: "main"
5. Select folder: "/ (root)"
6. Save
